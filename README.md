# Reiko Booklet

Reiko 的私人视觉小册子，第一版只包含页面骨架和可调整的视觉系统。

## 打开

用现代浏览器直接打开 `Reiko-booklet.html`。无需安装依赖，也无需构建。

默认 A5 竖版 24 页，包含封面与封底，可切换为 20 或 22 页。支持全部页面、双页与单页预览。

## 调整

- 点选页面，然后改变该页版式。
- 纸色、字体、边距和文字比例是全册设置。
- 文字框可直接输入；图片框可选择本地图片。
- 点“保存项目”下载 JSON 文件，下次用“打开项目”恢复。浏览器不会自动保存修改。
- “打印 / 导出 PDF”使用浏览器打印功能，目标纸张为 A5，辅助框及占位提示不打印。

当前版式由单文件中的 `layouts` 定义，默认页序由 `sequence` 定义，视觉变量位于 CSS `:root`。后续可以拆分为 CSS、JavaScript 和项目数据文件。

## 内容边界

不预写私人内容，不编造日记、回忆、人物档案或虚构文字。骨架采用留白、短句、图像、长短记录和散置档案的不同组合，视觉风格仍可继续调整。

## 验证状态

已检查脚本执行、默认空白状态、页数切换、内容保留、单双页切换和 JSON 序列化。当前环境尚未完成真实浏览器视觉检查、打印输出检查和实际保存恢复的端到端检查，继续修改时需要补做。

## 私人数据

保存的 JSON 会包含你输入的文字和选入的图片。私人内容填入后，应留在本机或私人仓库。
